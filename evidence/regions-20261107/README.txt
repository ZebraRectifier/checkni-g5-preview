ОБЯЗАТЕЛЬНАЯ ЗАВИСИМОСТЬ ПЕРЕД ПУБЛИКАЦИЕЙ

В базовом опубликованном приложении regionalDirectoryHosts в
src/intelligence/nearbyShopping.mjs ещё не включает magnit.ru.
Поэтому эти данные сами по себе не сделают новые адреса видимыми.
Сначала основной чат отдельно выпускает узкое разрешение magnit.ru
в проверке официальных источников и регрессию региональной выдачи.
Затем публикуется этот data-only PR и выполняется проверка живой выдачи.
Источник не подменяется на OSM ради прохождения фильтра.
На момент подготовки этого пакета новые адреса НЕ опубликованы.

ОТКУДА ДАННЫЕ

Официальный справочник: https://magnit.ru/shops
Публичный читающий endpoint:
https://magnit.ru/webgate/v1/stores-facade/search/detail

Запросы без ключей, авторизации, cookie и создания сессий. Формат запроса
взят из открытого JS справочника. Ограничение страницы — 50 точек, запросы
последовательные с паузой; только продуктовые MM/MM_MINI/GM. В каждой
добавленной записи подтверждены isActive=true, STATUS_ACTIVE, офлайн-доступ,
номер дома и попадание координат в административный полигон города.
Для идентификаторов сохранены ведущие нули (например 010852).

source-manifest.json содержит точные запросы, HTTP-статусы, время получения,
SHA256 и размер исходных ответов. source/**.json.gz — полные JSON-ответы,
сжатые без изменения распакованных байтов. Проверка не обращается к сети.
Административные границы взяты из OSM-снимка 05.11.2026; ссылки на relation,
лицензия ODbL-1.0 и контрольные суммы хранятся рядом. Исходная атрибуция
каждого опубликованного городского набора сохранена.

ЧТО ОТСЕЯНО И ЧТО ОСТАЛОСЬ НЕИЗВЕСТНЫМ

Официальные поиски вернули 1836 строк. После удаления повторных ID и
фильтра границ осталось 1529 действующих продуктовых точек Магнита.
Из них 256 сопоставлены с уже имеющимися адресами; 631 оставлена в
review.json из-за близких координат, совпадающих адресов или разных ID.
642 отдельные подтверждённые точки подготовлены для добавления.

Пагинация источника нестабильна: одинаковые ID повторяются между страницами.
Поиск по названию города также находит похожие названия улиц вне города.
Поэтому 1529 — число проверенных полученных точек, НЕ полное покрытие города,
не число всех магазинов и не доказательство отсутствия других точек.
Счётчики и решения по каждой записи даны в coverage.json и review.json.

Старая очередь 742 спорных картографических записей не объявлена закрытой:
СПб 395, Казань 66, Екатеринбург 89, Новосибирск 28, Нижний Новгород 164.
223 близких совпадения с новым официальным справочником служат подсказками
для сверки, но сами по себе не доказывают идентичность точек. Эта очередь
может пересекаться с новым review; складывать их как уникальные магазины нельзя.

13 официальных точек METRO из текущего справочника повторно найдены по ID
и тем же координатам; новых точек METRO в этот пакет не добавлено.
О'КЕЙ вернул HTTP 403, Лента HTTP 401; ВкусВилл — timeout соединения.
Ограничения доступа не обходились. Остальные сети не получили в этом пакете
новой официальной проверки и не считаются автоматически обновлёнными.

ПРОВЕРКА И УСЛОВИЯ ПРИЁМКИ

Запустить из корня репозитория:
node --test evidence/regions-20261107/validate.mjs

Проверяется сохранность всех старых записей и источников, хеши распакованных
ответов, статус/формат каждой новой точки, принадлежность городскому полигону,
уникальные ID, отсутствие близких дублей и любых catalogBinding/price/stock,
совместимость новых JSON с существующим bounded directory loader.

Перед объединением data-only PR проверить соответствующий выпуск allowlist.
После публикации открыть каждый из пяти городов и точку рядом с новым адресом:
магазин должен появиться в своём городе с адресом, а неподключённый каталог
не должен превратиться в доступную корзину. Проверить также перезагрузку,
геолокацию, переключение города и отсутствие попадания этих точек в Москву.
Браузерная проверка именно этих новых данных на живом сайте пока не проводилась.
